# Уведомления о стороннем коде

BlackRabbitMQ использует следующие библиотеки. Их лицензии приведены ниже.

## AMQP-CPP

Реализация протокола AMQP 0.9.1.
Лицензия Apache License 2.0.
https://github.com/CopernicaMarketingSoftware/AMQP-CPP

## POCO C++ Libraries (Windows)

TCP-сокеты и опрос событий на Windows.
Лицензия Boost Software License 1.0.
https://pocoproject.org

## libevent (Linux)

Цикл обработки событий на Linux.
Лицензия BSD 3-Clause.
https://libevent.org

## OpenSSL

Шифрование соединений (TLS).
Лицензия Apache License 2.0.
https://www.openssl.org

## nlohmann/json

Разбор и формирование JSON для заголовков сообщений и событий.
Лицензия MIT.
https://github.com/nlohmann/json

## Google Test

Каркас автотестов (используется только при сборке тестов, в поставку
компоненты не входит).
Лицензия BSD 3-Clause.
https://github.com/google/googletest

## 1С:Предприятие Native API

Заголовочные файлы SDK внешних компонент (`src/AddIn1S/sdk/`) поставляются
фирмой «1С» вместе с технологией внешних компонент и используются в
неизменном виде.
