# BlackRabbitMQ

Внешняя Native API компонента для работы с RabbitMQ из 1С:Предприятие 8.3.
Очереди, обменники, публикация с подтверждением брокера и доставка сообщений
прямо в код 1С — без прослоек, прокси и шины.

C++17, потокобезопасность, событийная модель без опроса.
Windows и Linux, 32 и 64 бита.

**Сайт проекта:** https://neonvalve.github.io/BlackRabbitMQ/

## Что умеет

- **Публикация с гарантией** — управление возвращается только после
  подтверждения брокера; сообщение с неверным ключом маршрутизации даёт
  ошибку, а не исчезает молча
- **Приём без опроса** — компонента сама доставляет сообщения в
  `ОбработкаВнешнегоСобытия`; в простое процессор не тратится
- **Режим опроса** — `BasicConsumeMessage` для фонового задания на сервере
- **Ручное подтверждение** — `BasicAck` после обработки, `BasicReject`
  с возвратом в очередь или без
- **Полное управление топологией** — обменники, очереди, привязки,
  приоритеты, заголовки, свойства сообщений
- **Бинарно-безопасные тела** — передаются по длине, не обрезаются на `\0`

## Быстрый старт

```1c
ПодключитьВнешнююКомпоненту("ОбщийМакет.BlackRabbitMQ");
Клиент = Новый("AddIn.BlackRabbitMQ");

Клиент.Connect("localhost", 5672, "guest", "guest", "/", 0, Ложь, 30);
Клиент.BasicPublish("myexchange", "orders.new", "{""orderId"": 123}", 0, Истина, "");
Клиент = Неопределено;
```

### Установка компоненты

Готовый ZIP берётся со [страницы релизов](https://github.com/neonvalve/BlackRabbitMQ/releases)
(внутри `MANIFEST.XML` и бинарники под Linux и Windows) и добавляется в
конфигурацию как общий макет с видом «Двоичные данные».

### Сборка

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# ZIP-пакет компоненты для текущей платформы → build/dist/
cmake --build build --target package1c
```

## Платформы

- Linux (GCC/Clang, libevent) — сервер 1С
- Windows (MSVC, POCO), x86_64 и i386 — сервер и клиентские машины
